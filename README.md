## Descripción

Repositorio correspondiente a la tercera actividad de la asignatura de Programación Orientada a Objetos.

En esta actividad se desarrollan diferentes ejercicios utilizando el lenguaje de programación Java.

## Ejercicios

1. **Notas:** creación de un programa para promediar notas de un estudiante.
2. **Figuras geométricas:** creación de un programa en Java para representar figuras geométricas y calcular su volumen y superficie.

## Tecnologías

* Java
* NetBeans

## Estructura del proyecto

Los ejercicios se encuentran organizados dentro del paquete `src` del proyecto `Actividad_3_POO`.
